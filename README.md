# Roll Into Dungeon

2026 NHN 해커톤 출품작. 3개의 주사위를 굴려 생성된 공격력(ATK)과 방어력(DEF)으로 적을 물리치는 턴제 주사위 전략 배틀 게임입니다.
플레이어는 각기 다른 특성을 가진 주사위를 조합해 스테이지(라운드)에 입장하며, 리롤과 락 시스템을 통해 운을 실력으로 통제하는 전략적 재미를 느낄 수 있습니다.

- **목표**: AI 바이브 코딩을 활용한 빠른 개발
- **개발 인원**: 2인 (김진선, 김호준)

## 🎮 실행 방법

## 플레이 방법

- **조작법**: 마우스 좌클릭 전용
- **로비 화면**: 사용할 주사위 3개를 선택한 후 [던전 입장] 버튼을 눌러 스테이지를 시작합니다.
- **주사위 굴리기**: 턴이 시작되면 [다시 굴리기] 버튼을 눌러 주사위를 굴립니다. (턴당 최대 3회)
- **주사위 고정/해제**: 판 위에 있는 주사위를 클릭하면 '고정', 고정된 주사위를 한 번 더 클릭하면 '고정 해제'됩니다.
- **전투 진행**: 원하는 주사위 값이 맞춰지면 [전투하기] 버튼을 누릅니다. 최종 확정된 주사위 값(공격력/방어력)으로 적을 공격하며 전투가 진행됩니다.

## 핵심 시스템

### 주사위 덱 구성

게임 시작 전 아래 4종류의 주사위 중 3개를 선택해 라운드에 입장합니다. 상대할 적의 특성에 맞춰 공격에 집중할지, 공방 밸런스를 맞출지 전략적인 세팅이 필요합니다.

| 주사위 | 구성 |
|---|---|
| 공격형 (All ATK) | 모든 면이 공격 (1~6) |
| 방어형 (All DEF) | 모든 면이 방어 (1~6) |
| 혼합형 DA (Odd ATK) | 홀수(1,3,5) 공격 / 짝수(2,4,6) 방어 |
| 혼합형 AD (Even ATK) | 홀수(1,3,5) 방어 / 짝수(2,4,6) 공격 |

### 턴 진행 및 전투 룰

1. **주사위 굴리기**: 플레이어 턴 시작 시 3개의 주사위를 굴립니다. 턴당 최대 3번까지 다시 굴릴 수 있습니다.
2. **주사위 고정 (Lock)**: 원하는 값이 나온 주사위는 고정할 수 있으며, 고정된 주사위는 리롤해도 숫자가 변하지 않습니다.
3. **트리플 잭팟**: 3개의 주사위가 모두 같은 숫자가 나오면 콤보가 발동되어 최종 공격력에 x3 배율이 적용됩니다.
4. **적의 반격**: 플레이어의 공격 및 턴이 종료되면 적의 턴이 시작됩니다. 적은 공격력만큼 플레이어에게 피해를 입히며, 플레이어는 확보한 방어력으로 이를 상쇄해야 합니다.

## 적 및 스테이지 구성

라운드는 여러 몬스터를 모두 섬멸해야 클리어되는 구조이며, 각 몬스터는 고유의 체력/공격력/방어력 스탯을 가집니다.

**일반 몬스터**
- Mushroom (머쉬룸)
- Skeleton (스켈레톤)
- Flying Eye (플라잉 아이)
- Goblin (고블린)

**보스 몬스터**

막강한 기본 스탯 외에도 전투의 판도를 바꾸는 특수 패턴을 보유합니다.
- **페이즈 전환 패턴 (부하 소환)**: 보스 체력이 50% 이하로 떨어지면 스켈레톤 1마리를 추가로 소환합니다. (전투 중 1회 발동)
